# Great Expectations Learning

A project-based journey to learn Great Expectations (GX) with Python.

The goal is to build practical data-quality skills through progressively
more difficult projects, from basic validation to production-style
data-engineering workflows.

## Goals

By completing these projects, I aim to be able to:

- Build GX validation workflows in Python
- Design useful data-quality expectations
- Validate schemas and data
- Handle validation failures
- Integrate GX into Python pipelines
- Build automated data-quality gates
- Test data-quality workflows
- Handle schema evolution
- Design maintainable production-style validation systems
